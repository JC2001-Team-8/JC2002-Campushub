## 1. 切片开工前检查清单

| # | 检查项 | 合格标准 | 留痕 |
| --- | --- | --- | --- |
| 1 | 角色已认领 | 后端主办、后端协办、前端主办三人明确；切片 2 协办可复用切片 1 协办 | 群内认领记录 |
| 2 | 文件清单已贴群并确认 | 按目录列出完整路径（Java、迁移、前端页面），经后端负责人确认 | 群消息 + 确认回复 |
| 3 | operationId 清单已摘出 | 从 `ITERATION-PLAN-VERTICAL-SLICES.md` 第 5 章复制本片行，形成本片清单；数量与 15/10/30/28 对应 | 本片清单文件/群消息 |
| 4 | 表归属与受限写已摘出 | 从 `ITERATION-PLAN` 附录 A 复制本片表清单、受限写字段、例外编号（E-01~E-10） | 本片清单 |
| 5 | 前片公开方法已确认存在 | 例如切片 3 开工前确认切片 2 已提供「占用 / 释放」方法；切片 4 确认切片 2 的下架/释放、切片 3 的取消/作废方法 | 接口签名截图或链接 |

**不合格处置**：任一项未完成不得开工；不得以「先写起来再说」绕过。

## 2. 每个 PR 的审查清单（6 项）

| # | 检查项 | 具体操作 | 不通过示例 |
| --- | --- | --- | --- |
| 1 | 是否只改本片文件 | `git diff --stat` 与开工前清单逐条比对；清单外文件即越界 | 切片 3 的 PR 改了 `ItemController` |
| 2 | 是否与 `openapi.yaml` 一致 | 路径、方法、请求/响应 DTO、枚举、权限声明、幂等声明逐项对照 | 响应字段写成 `price` 而契约是 `estimatedPrice` |
| 3 | 状态转换是否条件更新，占用与投影是否同事务 | 检查 `UPDATE ... WHERE id=? AND status=?` / `WHERE version=?`；检查写 `item_occupations` 与改 `items.status` 是否同一事务 | 「先查再无条件更新」；先写台账后异步改状态 |
| 4 | 错误码是否来自 `error-codes.md` | 逐个错误码在 `error-codes.md` 检索；新增码必须走契约变更 | 自造 `ITEM_OCCUPIED` |
| 5 | 是否有对应测试（含并发与幂等） | 至少有本片主流程用例；状态转换类至少有 ≥2 并发用例；16 个必填幂等接口逐一有用例 | 只有 happy path，没有 409/403 用例 |
| 6 | 是否引用他片 `ServiceImpl` 或独占表 | 搜索 `import ...service.impl`；检查是否直接写他片独占表（例外 E-01~E-10 除外） | 切片 3 注入 `ItemServiceImpl`；直接 `UPDATE items` |

**审查结论**：6 项全部通过才允许合并；任一项不通过退回归属片修改，**下一片审查人不得直接替改**。

## 3. 切片闭合现场检查清单

> 闭合评审现场执行，不接受「我本地是好的」口头结论。

| # | 动作 | 通过标准 | 留痕 |
| --- | --- | --- | --- |
| 1 | `mvn clean package -DskipTests` | 输出 BUILD SUCCESS | 终端输出截图/粘贴 |
| 2 | `curl -fsS http://localhost:8080/actuator/health` | 返回 200 | 命令输出 |
| 3 | 跑上一片冒烟脚本 | 全部通过 | 脚本输出 |
| 4 | `shasum -a 256 ../docs/iteration1/design/openapi.yaml` | 前 16 位 `36bd7a03a184734c` | 命令输出 |
| 5 | `git diff --stat` | 文件集合 ⊆ 开工前清单 | 并排比对截图 |
| 6 | 10 项交接清单 | 逐项打勾并签字 | 第 4 章签字表 |

**额外核对（建议，不替代上表）**

- `git log --format='%an' | sort | uniq -c` 查看提交作者分布（防代提交）。
- PR 行数抽查（防一次性大提交）。
- 4 个迁移哈希与 `HANDOVER` 基线一致（防改迁移）。

**任一项失败**：闭合不通过，不得交棒；阻塞项本片解决，或把 operationId 移出并登记。

## 5. Agent 使用规范

| # | 规范 | 操作 |
| --- | --- | --- |
| 1 | 指令必须自带约束 | 每次给 agent 的指令包含：本片 operationId 清单、本片表归属与受限写、相关契约片段、错误码清单、禁止修改的文件 |
| 2 | 生成后逐项核对 | 字段名、类型、required、枚举取值、错误码、金额格式（字符串 `"120.00"`）、时间格式（ISO 8601 UTC） |
| 3 | 随机抽查 | 随机取 3 个字段名/枚举值/错误码，在 `../docs/iteration1/design/schema.md` 与 `../docs/iteration1/design/error-codes.md` 中 `grep` 到源头 |
| 4 | 禁止「看起来对」 | AI 生成代码必须跑本地编译 + 本片自测后才可提交；字符串、映射、注解值错误编译不报错 |
| 5 | 禁止跨片投喂 | 不要求 agent 同时理解多个切片；一次只做一个明确的小目标 |

**agent 指令模板（最小集）**

```text
切片：<N>
本片 operationId：<从 ITERATION-PLAN 第 5 章复制>
本片表：<独占 / 只读 / 受限写字段 + 例外编号>
契约片段：<openapi.yaml 中相关 path + schema>
错误码：<只允许 error-codes.md 中已登记的码>
禁止修改：其他切片的 Controller/Service/ServiceImpl/Repository/Entity；openapi.yaml；V1~V4；公共层（除非本片就是切片 1）
验收：<本片交付标准中与本任务相关的条目>
```

## 6. 常见跑偏场景与拦截方式

| # | 跑偏场景 | 识别信号 | 拦截方式 | 拦截时点 |
| --- | --- | --- | --- | --- |
| 1 | 字段漂移 | 字段名在 `schema.md` / `openapi.yaml` 找不到 | 契约测试 + PR 第 2 项 | PR 审查 |
| 2 | 越界改他片文件 | `git diff --stat` 出现清单外文件 | 清单逐条比对（PR 第 1 项） | PR 审查 / 交棒 |
| 3 | 自造错误码 | `grep error-codes.md` 无命中 | PR 第 4 项；新增码必须走契约变更 | PR 审查 |
| 4 | 两段式更新（先查后改） | 代码出现「查 → 判断 → 无条件 update」 | 审查条件更新语句与影响行数判断 | PR 审查 |
| 5 | 占用与投影分事务 | 写台账与改商品状态不在同一事务 | 审查事务边界（PR 第 3 项） | PR 审查 |
| 6 | 带病交棒 | 测试红 / 编译错 / 冒烟失败 | 闭合现场构建 + 冒烟脚本 | 闭合评审 |
| 7 | 代提交 | 提交作者只有 1 人但声称多人参与 | 作者分布检查 + 每人自己账号 | PR / 交棒 |
| 8 | 一次性大提交 | PR 上千行、跨多个模块 | PR 行数与文件数检查；要求拆分 | PR 审查 |
| 9 | 改迁移脚本 | 4 个迁移哈希变化 | `shasum` 核对（闭合第 4 项之外的迁移核对） | PR / 交棒 |
| 10 | 前端自算倒计时 | 前端用本机时间推算剩余 | 代码审查 + 联调验证只用 `expiresAt`/`remainingSeconds` | 联调 / 交棒 |
| 11 | 交换出现「部分接受」 | 前端提供物品级勾选或后端接收 `itemIds` 子集 | 契约与 R-22 核对；只保留整包接受 | PR / 联调 |
| 12 | 只测 happy path | 无 401/403/409/422 用例 | PR 第 5 项要求错误分支与并发/幂等用例 | PR 审查 |
