## 1. 阅读说明

1. 页面编号 `PF-xx`，流程编号 `FL-xx`，流程步骤编号 `FL-xx-Sx`。
2. 每个页面标注：**路径建议**、**访问权限**、**核心元素**、**依赖接口域**（域级，不含具体接口清单）、**状态依赖**。
3. 「依赖接口域」指向接口清单中的资源域，便于后续接口清单反向核对**是否有页面需要但接口未列**。
4. 迭代一只交付**页面清单 + 路由占位骨架**，不交付交互实现。

## 3. 页面详情

### PF-01 首页 / 分类商品列表

| 项 | 内容 |
| --- | --- |
| 访问权限 | 公开（访客可见；受限用户可见但顶部展示处罚提示） |
| 核心元素 | 分类导航（预设分类）；商品卡片流（封面图、标题、估价、成色、所在交易区域、交换状态徽标）；排序切换（最新优先）；筛选（分类、交易区域、交换状态）；分页或滚动加载；登录/注册入口；购物车入口（登录后） |
| 状态依赖 | 仅展示商品状态 = 在售（`IN_SALE`）；`RESERVED`/`SWAPPING` 商品默认不出现在列表 |
| 依赖接口域 | 商品列表、分类字典、交易区域字典、登录态 |
| 关键交互 | 点击卡片 → PF-02；未登录点击「加入购物车」→ 引导 PF-04 |
| 空态 | 无商品时展示引导发布（登录后）/引导注册（未登录） |

### PF-02 商品详情

| 项 | 内容 |
| --- | --- |
| 访问权限 | 公开 |
| 核心元素 | 图片轮播（1–9 张，首图封面）；标题；成色；**估价（标注「用户自填，仅供参考」）**；所在交易区域；**卖家交换状态**（可交换/暂不交换/交换中/已交换）；卖家昵称与头像；发布时间；操作区（加入购物车、立即购买、发起交换、举报）；自己发布时操作区替换为（编辑、下架/重新上架、交换状态设置） |
| 状态依赖 | `IN_SALE`：全部操作可用；`RESERVED`：加购/下单/发起交换均禁用并提示已预订；`SWAPPING`：提示交换中；`SOLD`/`OFF_SHELF`/`BANNED`：仅展示并提示不可交易 |
| 依赖接口域 | 商品详情、商品图片、卖家公开资料、举报、购物车 |
| 关键交互 | 加入购物车 → 停留或跳 PF-09；立即购买 → PF-10；发起交换 → PF-16；举报 → PF-24 |
| 受限用户 | 操作按钮禁用 + 提示解封时间 |

| --- | --- |
| 访问权限 | 公开 |

| 状态依赖 | — |
| 依赖接口域 | 注册 |
| 关键交互 | 注册成功 → 自动登录进入 FL-01 后续步骤（勾选交易区域） |
| 备注 | 是否需要邮箱验证：假设**不需要**（Q-06） |

| 项 | 内容 |
| --- | --- |
| 访问权限 | 公开 |

| 状态依赖 | 被处罚用户**可正常登录**，登录后跳转 PF-05 并展示处罚提示 |
| 依赖接口域 | 登录、当前用户 |
| 关键交互 | 登录成功 → 返回来源页或 PF-01；失败 → 停留并提示 |

### PF-05 个人主页

### PF-06 编辑资料

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人（受限用户：可进入但昵称/头像禁改，交易区域可改，见矩阵 §8） |
| 核心元素 | 昵称输入；头像上传/更换/删除；**常用交易区域多选（1–5 个，预设列表勾选）**；保存；修改密码入口 |
| 状态依赖 | 受限用户此处按钮禁用并提示 |
| 依赖接口域 | 资料更新、头像上传、交易区域字典、密码修改 |
| 关键交互 | 保存成功 → 返回 PF-05；区域必须≥1 且≤5 |

### PF-07 发布商品

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人（受限用户禁止进入或进入后禁用提交） |
| 核心元素 | 标题；分类下拉；成色下拉；估价输入（≥0，两位小数）；交易区域下拉（**仅本人已勾选区域**）；图片上传（1–9 张，首图封面）；描述（可选）；是否接受交换；发布按钮 |
| 状态依赖 | 未勾选任何交易区域时，先引导至 PF-06 |
| 依赖接口域 | 商品创建、图片上传、分类/成色/区域字典 |
| 关键交互 | 发布成功 → PF-08 或 PF-02；字段级错误提示 |
| 校验提示 | 缺必填逐项提示；>9 张图或 >5MB 明确提示 |

### PF-08 我的物品

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人 |
| 核心元素 | 按状态分组的商品列表（在售/已预订/交换中/已售出/已下架/违规下架）；每项操作：编辑、下架、重新上架（违规下架项**无**重新上架按钮）、设置交换状态；占用状态徽标（被订单占用 / 被交换占用） |
| 状态依赖 | 占用态商品的编辑入口禁用并说明原因；`BANNED` 项展示下架原因 |
| 依赖接口域 | 我的商品列表、商品操作、占用信息 |
| 关键交互 | 编辑 → PF-07（编辑态）；交换状态 → PF-14 |

### PF-09 购物车

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人（受限用户可查看但不可结算） |
| 核心元素 | **按卖家分组的条目列表**；每组的商品缩略信息（图、标题、估价、成色、区域）；失效条目（已被占用/售出/下架）以灰色展示并标注原因；每组勾选框；底部合计（**估价合计，标注仅供参考**）；结算按钮 |
| 状态依赖 | 失效条目不可勾选；跨卖家勾选时提示将拆成多笔订单 |
| 依赖接口域 | 购物车查询/修改/移除、商品有效性校验 |
| 关键交互 | 结算 → PF-10；受限用户结算按钮禁用 + 提示 |

### PF-10 提交订单（确认页）

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人 |
| 核心元素 | 待下单商品清单与**估价快照**；**按卖家拆分后的订单预览**（若跨卖家，明确展示将生成 N 笔订单，每笔独立倒计时与付款）；交易区域确认；提交订单按钮；错误区 |
| 状态依赖 | 提交前须校验所有商品仍在售未被占用 |
| 依赖接口域 | 订单创建（含幂等键）、购物车 |
| 关键交互 | 提交成功 → PF-11（若拆单，展示订单列表）；失败（商品被占）→ 提示并回 PF-09 刷新 |
| 幂等提示 | 前端必须**防重复点击**并携带幂等键 |

### PF-11 订单详情（含付款倒计时）

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人（买卖双方看到各自视角的操作区） |
| 核心元素 | 订单号、状态；商品清单与估价快照；**付款倒计时「已为你保留，剩余 mm:ss 付款」**（服务端时间驱动）；交易区域；取货点（已选则展示，未选则提示选择）；订单时间轴（下单/付款/选点/交付/确认）；操作区：买家（付款、取消、选择取货点、确认收货）、卖家（标记已交付）；超时后倒计时区域替换为「已超时取消」 |
| 状态依赖 | 严格按订单状态机展示可用操作；终态无操作区 |
| 依赖接口域 | 订单详情、模拟付款、取消订单、交付、确认收货、取货点 |
| 关键交互 | 付款 → PF-12；选点 → PF-13；确认收货 → 状态刷新为已完成并露出评价入口 |
| 幂等提示 | 付款/确认收货按钮必须携带幂等键，重复点击不得产生二次副作用 |

### PF-12 付款结果页

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人 |
| 核心元素 | 结果标识（成功/失败/已超时）；订单摘要；**明确标注「模拟付款，未产生真实扣款」**；后续动作（去选择取货点、返回订单列表） |

| 依赖接口域 | 订单详情、模拟付款结果 |
| 关键交互 | 「去选择取货点」→ PF-13 |

### PF-13 选择公共取货点

| 项 | 内容 |
| --- | --- |

### PF-15 交换包编辑（我的交换包）

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人 |
| 核心元素 | 交换包列表（状态：草稿/已打包/交换中/已占用/已释放/已完成）；新建交换包；包内物品管理（从「我可交换的在售商品」中挑选，**1–5 件**，超出即禁用添加）；**估价合计展示（标注仅参考、不做差价）**；打包完成/删除；被进行中提议引用的包为**只读** |

### PF-16 发起交换

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人 |
| 核心元素 | 目标商品摘要（来自 PF-02，可能为多件）；**选择我的交换包**（仅可用状态的包）；交易区域确认（必须与目标商品一致）；交换说明（可选）；双方估价合计对照（**仅展示，含免责说明**）；发起按钮；错误区 |
| 状态依赖 | 目标商品必须为「接受交换」且未被占用；同交易区域校验 |
| 依赖接口域 | 交换提议创建（幂等键）、我的交换包、商品详情 |

### PF-17 交换提议详情

| 项 | 内容 |
| --- | --- |
| 访问权限 | 本人（提议双方，各自视角） |
| 核心元素 | 提议状态与**剩余有效时间（72 小时倒计时）**；双方信息；我的交换包物品清单与估价合计；对方物品清单与估价合计；**操作区**：<br>· 目标方（`PENDING`）：**整包接受** / 拒绝 / 反提案<br>· 发起方（`PENDING`）：取消<br>· 反提案受理方（新提议的 `PENDING`）：接受 / 拒绝<br>· 已 `ACCEPTED`：查看交换码入口、确认交付/收到<br>· 终态：仅展示结果与原因（拒绝/过期/取消/作废） |
| 状态依赖 | 严格按交换提议状态机展示；**接受为整包，界面不得提供物品勾选**（OOS-04） |
| 依赖接口域 | 交换提议详情、接受/拒绝/反提案/取消、确认动作 |
